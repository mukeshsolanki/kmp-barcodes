Generate and scan barcodes, with no network call

A barcode library for Android, iOS, Kotlin Multiplatform and Compose Multiplatform, built on a pure Kotlin port of ZXing 3.5.3. QR Code, Data Matrix, Aztec, PDF417 and the common 1D formats.

Latest release: @VERSION@

Choose a library

  • kmp-barcodes-core to encode, decode still images and build payloads, with no Compose.
  • kmp-barcodes for Compose painters and image export. It includes kmp-barcodes-core.
  • kmp-barcodes-scanner for the Compose camera scanner. It includes kmp-barcodes-core.

Install

Android, KMP and Compose Multiplatform

Add the Maven repository to your settings file:

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        maven("https://mukeshsolanki.github.io/kmp-barcodes")
    }
}

Then add the dependencies you need:

// build.gradle.kts
implementation("com.mukeshsolanki.barcodes:kmp-barcodes:@VERSION@")         // generation, includes core
implementation("com.mukeshsolanki.barcodes:kmp-barcodes-scanner:@VERSION@") // camera scanner, includes core

Requirements:

  • Android: minSdk 24.
  • iOS: iOS 15 and Kotlin 2.4 or newer.
  • Compose: built with Kotlin 2.4.21 and Compose Multiplatform 1.12.2.

Swift (Swift Package Manager)

Add this package, then choose one product:

https://github.com/mukeshsolanki/kmp-barcodes
  • KmpBarcodes: generation, plus core.
  • KmpBarcodesScanner: the camera scanner, plus core.

Each XCFramework embeds its own copy of core. Don't link both, because each would have its own incompatible Barcode type.

iOS simulators on Intel Macs aren't supported.

Usage

import com.mukeshsolanki.barcodes.PixelShape
import com.mukeshsolanki.barcodes.QrStyle
import com.mukeshsolanki.barcodes.rememberBarcodePainter

val painter = rememberBarcodePainter(
    content = "https://example.com",
    style = QrStyle(darkPixel = PixelShape.Circle),
)
Image(painter, contentDescription = "QR code")
import com.mukeshsolanki.barcodes.BarcodeFormat
import com.mukeshsolanki.barcodes.BarcodeScanner
import com.mukeshsolanki.barcodes.rememberScannerState

val state = rememberScannerState()
BarcodeScanner(
    state = state,
    formats = setOf(BarcodeFormat.QrCode),
    onResult = { barcode -> println(barcode.text) },
)
import com.mukeshsolanki.barcodes.scanImage

val barcode = scanImage(bytes) // null when nothing reads

Camera permission

The library never requests permission. Request camera access in your app before showing the scanner, and declare it:

<uses-permission android:name="android.permission.CAMERA"/>
<uses-feature android:name="android.hardware.camera" android:required="false"/>

On iOS, add NSCameraUsageDescription to Info.plist.
